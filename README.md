🎯 QuizMaster – Interactive JavaScript Quiz App

QuizMaster is a simple and interactive quiz application built using HTML, CSS, and JavaScript. It allows users to test their programming knowledge through multiple-choice questions and view their final performance.

🚀 Live Demo

Add your deployed website link here.

📌 Features

* 10 Programming Questions
* One Question at a Time
* Multiple Choice Options
* Instant Correct and Wrong Answer Feedback
* Progress Bar
* Final Score and Percentage
* Answer Review System
* Restart Quiz Option
* Dark and Light Mode
* Best Score using LocalStorage
* Responsive Design for Mobile Devices

🛠️ Technologies Used

* HTML5 – Website Structure
* CSS3 – Styling and Responsive Design
* JavaScript – Quiz Logic and DOM Manipulation
* LocalStorage – Saving Theme and Best Score

💻 How to Run Locally

1. Clone this repository:

git clone https://github.com/kartikshete/interractive-javascript-app.git

2. Open the project folder:

cd interractive-javascript-app

3. Open index.html in your browser or use the VS Code Live Server extension.

🎮 How to Use

1. Open QuizMaster.
2. Click on Start Quiz.
3. Select the correct answer from the available options.
4. Click Next Question.
5. Complete all 10 questions.
6. View your final score and percentage.
7. Review your answers or restart the quiz.
